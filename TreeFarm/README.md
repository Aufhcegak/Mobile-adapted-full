# TreeFarm 林场

一座由罗宾建造的大型林业基地：大堂中枢电脑统一管理多个树种林区，自动种植、自动生长、自动砍伐，产出原版树脂等林业物资。

## 功能

- **大型林业基地**：60,000g + 木×500 + 石×100，罗宾 3 天建造，占地 7×4。
- **大堂中枢电脑**：状态 / 商店 / 管理 / 结算 / 升级 五页签，一站式管理整个林场。
- **多个林区**：不同树种分区管理，自动种苗、自动长成。
- **树龄收益曲线**：树龄越高树脂掉率越高，到砍伐线后自动砍伐。
- **原版产物**：产出使用原版物品（树脂等），不引入奇怪的新资源。
- **不砍也有收益**：橡/枫/松站树每天基础掉少量木头；装「树脂收集器」后还会再产树脂，不用等砍伐。
- **自动补种更完整**：买苗、手动砍伐、自动砍伐、扩容后，只要开着自动种植且有苗有空位，都会立即补种。
- **辅助道具**：速生液、伐木机等辅助林业生产。

## 安装

1. 安装 [SMAPI](https://smapi.io/)（4.x）。
2. 将本 Mod 解压到 `Stardew Valley/Mods/TreeFarm`。
3. 找罗宾建造「林场」，进入后使用大堂中枢电脑开始经营。
