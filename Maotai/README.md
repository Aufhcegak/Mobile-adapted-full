# 茅台 Maotai

星露谷物语 (Stardew Valley) 1.6 的酿酒 mod —— 在山谷里酿造正宗茅台，液体黄金，酱香冲天。

## 功能

- **合成茅台酿曲**：上古水果 ×1 + 任意蛋 ×1（耕种 3 级解锁配方；恐龙蛋需单独的「茅台酿曲(恐龙蛋)」配方，因为原版恐龙蛋分类是 0 不是蛋类 -5）→ 茅台酿曲
- **酿造茅台**：酿曲丢进小桶，**10000 分钟（约 6.25 天，与原版果酒完全一致）**出茅台
- **木桶陈酿**：茅台可以进木桶陈酿，陈酿曲线与果酒完全相同（银星 14 天 / 金星 14 天 / 铱星 28 天）
- **售价 2700g**：杨桃果酒（2250g）的 1.2 倍，真正的液体黄金（工匠专精再 +40%）
- **完全数据驱动**：纯 Content Patcher content pack，无 C#、无 Harmony，天然兼容所有模组

## 安装

1. 安装 [SMAPI](https://smapi.io/)（4.x，游戏 1.6.15+）与 [Content Patcher](https://www.nexusmods.com/stardewvalley/mods/1915)
2. 下载本 mod，放入 `Mods/Maotai/` 文件夹
3. 启动游戏，耕种 3 级后学会「茅台酿曲」配方

## 玩法

1. 收一个上古水果，掏一颗鸡蛋（任意蛋均可）→ 合成茅台酿曲
2. 酿曲丢进小桶 → 10000 分钟后开瓶
3. 2700g 一瓶，送给酒鬼们，山谷都安静了；想要更顶级的，丢进地窖木桶陈酿成铱星茅台（8100g）

| 茅台 | `(O)Claude.Maotai_Maotai`，分类 -26（工匠），tag/buff 照抄果酒 348（含 Tipsy 醉酒效果）|
| 酿造时间 | 10000 分钟（照抄原版果酒，约 6.25 天）|
| 售价 | 2700g = 杨桃果酒（2250）× 1.2；工匠专精 ×1.4 = 3780g |
| 木桶陈酿 | 与果酒同曲线：银星 4050 / 金星 5400 / 铱星 8100g |
