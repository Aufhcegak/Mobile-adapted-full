## 研究与配方

研究桌只显示当前一步。39 种作物可以任意顺序接取，也可以同时研究多种；普通架子科技仍按二层→三层→四层推进。
每天每个课题最多推进一步。材料交给样本台；交过的材料有收据，不会重复收。

小麦、南瓜、蓝莓、上古水果的观察和登记合为第二步：仍需在合适的原型架播种并检查幼苗，达到所列相位后到研究桌登记，可当天完成。已经检查过的观察会保留，不要求每天重看。旧版进行到最终登记步骤时，升级后保留已交材料与观察，直接去研究桌办理；未观察的课题仍要完成真实试种。其余课题流程不变。

无土栽培和小屋保温在双层架科技完成后可研究，各有四步和两种材料分支；分支都能完成。小屋保湿、外墙电脑在保温科技后开放，各有四步。
无土试验先做陶槽和回水管，再种防风草观察发芽，不要求成熟果实。研究结束会清掉实验苗，架子保留；共享课题仍需用这株菜时，等最后一项结束再清。
试验架占满时，到研究所**最右边的档案桌 → 清理试验架**。四个原型架各有按钮，点一次确认，再点清苗；架子、肥料和已交材料/观察记录保留，不退种或树苗、不算收获。

无土栽培只研究一次。每种无土架配方同时要求“无土栽培”与“对应层数的普通架科技”：

| 配方 | 原料 |
|---|---|
| 双层耕地架 | 木材×30、石头×5、纤维×10 |
| 三层耕地架 | 木材×45、铁锭×5、布料×2、精炼石英×5 |
| 四层耕地架 | 木材×60、硬木×20、铁锭×10、铱锭×2、电池组×1 |
| 双层无土架 | 双层耕地架原料，加黏土×5 |
| 三层无土架 | 三层耕地架原料，加黏土×10 |
| 四层无土架 | 四层耕地架原料，加黏土×15 |

例如先完成无土栽培、尚未完成四层架科技时，只得到已经学会层数的无土配方。以后完成四层科技，四层无土配方也会补上。

四层科技最后一次成熟甜瓜收获保留在s6；s7只验收铱锭5、硬木50，不再要求第二轮甜瓜。旧s7两项材料收据保留，完成奖励仍只发一次。

研究分支显示实际最早可验收日期，还需满足本阶段任务。同一天的基础等待可能与分支观察窗重合；界面不再宣称每次选择都额外累加相同天数。旧选项、日期和投入保留。

接取前显示试种投入和去向。按最低适合架，杨桃3粒、上古4粒、甜莓2粒；使用更高架按实际层数投种。短观察课题结题后收走不再共享的试株，不返种、不产果；有收获目标的课题仍先完成要求。完成后的档案可回查配方材料、最低层数、I/II特点及果树规则。

## 育种

完成某种作物的种植研究后，它下面就出现育种课题。39种各自研究、自由并行；任意一个育种课题完成，就获得两台共用机器的配方。每个课题同时开放本作物的I与II。

去研究所找玛鲁，在样本台左边两台机器试做。绿色育种器I管成色，粉色育种器II管丰产；拿普通种子右键放入对应机器。背包里同时准备材料：I用放射性矿石，II用金坷垃。每颗普通种子用1份，能多次收获的作物用5份；60个游戏分钟得到一颗对应优良种子。取出试做成品即登记，不要求成熟；三步课题仍每天最多推进一步。

| 内容 | 材料 / 效果 |
|---|---|
| 种子育种器I制造 | 放射性矿锭×5、精炼石英×20、电池组×5 |
| 种子育种器II制造 | 金坷垃×5、精炼石英×20、电池组×5 |
| 优良… I（右上绿标） | 原品质后各50%升一档或两档，铱星封顶 |
| 优良… II（右上粉标） | 原版与已有收获加成后，各种产物分别×1.5；半件独立50%补一件 |

机器不切模式，贴图不画I/II；种子保留原袋颜色与作物图案，只点缀右上小色签。具体用法由玛鲁的任务对话分三短页介绍，物品说明和缺料提示保持简短。

机器只加工已经研究过的普通种子，优良种子不重复加工；研究所试验机允许当前试做课题。缺料、错误种子、工作中和满包不会丢材料或成品。II需要实际安装金坷垃模组；缺此前置只授I，不生成假金坷垃。旧已完成课题会补II配方，保留已有I制造次数；旧机器在制品和剩余时间保留。

优良种子保留原种季节、生长、再生和地点限制。架上还是每层一颗，正常肥料和金坷垃照常用；丰产在它们结算后增加产出，向日葵花与副产种子分别计算。电脑能批量播种，F1可看优良种子与育种特点。

## 架上果树与产种

双层科技完成后，研究桌“果树”页出现樱桃、杏、橙、桃、石榴、苹果、香蕉、芒果八个独立课题，可以并行。每项把产种和架上栽培合在一起：用研究所产种机试做并取出苗，放到原型架，看两天新叶即可交结果，不要求14天长成或成熟水果；完课清试株保架。

一次加工要十个同品种、同星级水果，可跨背包或原版供料箱分堆；200游戏分钟出一棵同星级原版树苗。树苗不进种子育种器。任意首项果树研究完成，获得共同“果树产种机”配方：木材×100、精炼石英×20、铁锭×5、电池组×2。各品种仍各自完成课题后才能正式产种和上架；这份机器制造材料是本轮实现选定。

| 架子 | 果树苗投入 | 实际株数 |
|---|---|---|
| 双层土培或无土架 | 同品种苗×1 | 1 |
| 四层土培或无土架 | 同品种同星苗×2 | 2 |
| 三层架 | 不放果树 | 0 |

苗仍保留普通/银/金/铱星，架上全部统一14天长成，不因苗星加快。剪掉杂枝把小株留在两层高的空间，空出的托盘让开树冠；承载层、立柱和碰撞保留。每株沿原版果期每天一果、最多挂三果，果实星级按原版树龄，全年结果仍需要温室或保温小屋。

果树按原版成长，不把蔬菜的肥料、金坷垃或优良种子倍率套进它们的收成。架上已有的肥料/金坷垃保留，清树后继续种菜可用。普通菜架各层投入、独立收获、I/II和原自动化规则都保持。空手右键收果，斧头清树保架；研究所最右档案桌也可单独清一架，不退苗、不算收获。

电脑只管本屋架子，补给箱的树苗按品种与星级分按钮，一次种满目标2/4层空架；整批按实际1/2株扣苗，不把星级混凑。总览按实际果树株数算，位置图显示挂果与长成剩余天数。F1使用原生果树主体，同时显示架型、苗星、株数、挂果、水肥与原树龄品质。

特殊种法、同星要求、剪枝与清理都由果研任务中的玛鲁、罗宾、德米特里厄斯分开讲；常用UI不加常驻教程。当前果树手动上架/收果，朱尼摩不会把它当空菜架覆盖，原菜架地点矩阵保持。

## 种植与收获

耕地架装在空耕地上；无土架不用锄地，可放在原版允许摆放的空地或地板上。墙、家具、箱子、已有作物和其它占用格仍不能放。空架和种有作物的架子都会挡路。

站在邻格，拿种子或肥料按原版方法操作。一架一种作物，所有层一起生长；作物研究和最低层数要求仍适用。葡萄、啤酒花、青豆等攀缘作物与稻子、芋头不能上架。

- N 层播种用 N 颗种子；每次施一种肥料也用 N 份。分堆可凑足，缺料不扣。
- 已施肥的普通地装 N 层架，要为新增层补 N−1 份每种已有肥料，缺任意一种就不安装、不扣料。
- 浇一次水浇完整架；洒水器照常覆盖架子所在格。
- 收获时 N 层各走一次原版结算，星级、额外产物和金坷垃效果分别计算。生长加速、品质加成不会因为层数重复叠加。
- 草莓、蓝莓等再生作物保留植株并进入原版再生等待。手动收菜遇到背包满，可腾出位置后继续收剩余层。
- 无土架本身没有温室效果；季节和冬季枯萎沿用原版。温室、研究所和装好保温的农业小屋四季可种。
- 拿另一种普通肥料或生长激素右键架子，可以换掉原肥料。仍要N份，不退旧肥；相同肥料不再扣，换掉激素会重算原版生长天数。
- 架上不生成巨大作物；空架跨天和换月保留，换季不抹掉架子的普通肥料。

金坷垃可以手动施在架子上，与普通肥料按原模组规则共存。四层就用四份；种子、幼苗和成熟期的点击不会先被检查装置或收菜吞掉。
各层托盘分别显示湿土/水面、普通肥料和金坷垃；显示开关只影响水光，不改变供水或肥效。

## 农业小屋和外墙电脑

先完成“小屋保温”，罗宾才会出售农业小屋。建造与房间扩建继续找罗宾，室内地图、家具、占地和两天工期沿用普通小屋；新建15,000金、木材×300，扩建20,000金、木材×550、石头×300，不再把设备安装材料加进建筑造价。

新建的农业小屋要安装保温后才能全年种菜。旧0.2.0已经保温的农业小屋保留效果，更新不重收这份材料。普通小屋不能安装下面三项。

完成相应科技后，去研究所档案柜的“科技”页，选保温、保湿或外墙电脑，点“选择小屋”，轻点要安装的农业小屋，松手后安装。拖动地图只调整视角，左上方向按钮及移动按键也可移动；右上“返回”、Esc或已设置的菜单键取消选择。材料够了就当场装好；取消、点错建筑、材料不够或重复安装都不扣料。小屋和大农业小屋同价。

| 每栋安装 | 材料 | 效果 |
|---|---|---|
| 保温 | 煤炭×100、黏土×20 | 全年种植，作物不受季节限制 |
| 保湿 | 纤维×50、黏土×20 | 本屋土培架和无土架放下就有水，空架和有菜的架子都自动供水 |
| 外墙电脑 | 电池组×10、精炼石英×25 | 设备安装、种植架总览、补给箱与整屋作业 |

三项安装工期都是0，不开启罗宾施工或加班。保湿和电脑在保温科技后可分别研究，两者没有先后。研究时交的小份试做样本与上表每栋安装材料分开显示。

保湿只给这栋农业小屋里的两类架子供水，不给普通耕地和花盆保水。安装后已有干架也会湿；后来放下的架子立即有水，不必先浇一次。

电脑嵌在**屋外、门右侧的墙上**。站到电脑前轻触即可打开；电脑端仍可右键。它只管理这一栋农业小屋里的种植架，房间扩建仍找罗宾。

- **设备**：查看、安装本屋的保温、保湿和电脑。未学会的项目显示“先研究”。
- **种植架**：默认总览显示架数、株数、总种植位、空位/生长/可收/枯株色条与各品种表；点“位置图”查看实际摆放和单架水肥、生长详情，多品种可滚动。菜株按层数，果树按实际1/2株，枯株单列，不代表收获件数。
- **补给与作业**：打开原版补给箱，把种子、肥料、生长激素或金坷垃放进去，再点击对应材料按钮照料本屋架子。只有箱里有的种植材料会显示按钮；木材等杂物不占位。

按钮列出整批所需份数、箱里数量和能用的架子数。材料不够显示暗色；够全部目标架子才可执行。例如50个四层空架要200颗种子，放100颗只会出现暗按钮。种子只种空架，不收菜、不清枯株；普通肥料换掉原肥料，金坷垃独立保留。每层消耗一份。

按下按钮不立即扣料，移出后松手会取消。真正松手时再次检查建筑、架子和材料；中途失败会还原整批架子与材料。补给箱保留原版物品数量、品质和附加数据，正常移动或扩建会保留；箱里还有物品时不能拆除建筑。

小屋外墙不再加窗，已安装/未安装电脑各有完整建筑贴图；电脑外框与墙板一起绘制。贴地阴影沿实际斜墙角、底梁和支柱衔接，不再只沿图片底边画直线。NPC、任务目标与安装通知都指向屋外门右侧的电脑。移动或扩建房间后，三项状态跟着原建筑保留。

## 摆放与续收提示

架子保留实心碰撞。把20个架子铺成4×5实心块，会挡住内部架子的近身操作。推荐两组2×5，中间留一列通道，总矩形5×5共25格，其中20格是架子、5格是通道；两侧还应接入可走区域。指向底格会标出当前这一架的边界和层数，不把点击上层作物转到其它格。

收过一部分后，总览显示实际待收层数和本轮已收层数；再生作物已收层仍占位。研究所玩家自装架按普通生产架处理，可在空架时拆回。更新会保守去掉四个固定实验位以外的旧原型标记，保留架ID、植株、果树、肥料和其它modData。固定实验设备仍不能拆。

清苗界面每页最多4架，提供上一页/下一页；翻页和窗口改变会取消未提交确认。执行仍按架子稳定ID复核，不凭列表序号删除。

## F1 看架子

装有 Lookup Anything 时，指向空架按 F1 可看架型、层数和用途；有菜时显示“防风草 · 四层无土种植架”这样的合并主体。
详情保留原版作物的生长、售价和再生信息，并显示这架菜的投入、已收层数、水分、肥料和季节。
“肥料”一行没施肥写“无”；施过的名称合在一行，如“高级肥料 + 金坷垃”。名称来自这格实际的肥料和金坷垃标记，空架、有作物、耕地架和无土架都显示。原版作物的单格水肥行不重复显示。
F1头像让作物图占主要位置，架子轮廓放在旁边，二/三/四层与两种架型可辨；作物图仍来自原版。
Lookup Anything 1.53.0（官方标签源码构建）、1.54.0与1.55.0分别做了实际F1查询检查，适配没有修改它们的源码或运行DLL。其他联动核对版本为 Better Junimos 3.1.2、金坷垃 1.0.1、Junimo Qi Crop Fix 1.1.0；不需要替换这些模组。
适配遇到不兼容的接口时会在日志里说明，撤回本模组的查询补丁，保留原生查询。研究所和架子仍能加载；此时F1可能暂时没有架子专属字段。
