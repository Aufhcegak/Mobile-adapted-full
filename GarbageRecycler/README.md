# Garbage Recycler（垃圾回收机）

新增两类垃圾回收机：**水上垃圾回收机**和**陆地垃圾回收机**，并附带**水域监测站**，把水域污染与垃圾回收串成一套玩法。

## 功能

- **水上垃圾回收机**：像蟹笼一样放在水面上，每天自动打捞该水域的垃圾；每片水域限 1 台。
- **水域监测站**：空地放置后打开全部水域总览，可远程部署/收回水上机、远程净化水域、远程安装高效滤网，也可以直接打开水上机取垃圾/放饵料。
- **陆地垃圾回收机**：投入垃圾并添加燃料（煤/木头），每批最多处理 10 件，可混合不同垃圾种类，产物进入全局回收仓库。
- **净水滤芯**：对水面或水上机使用，立刻降低污染 10 点。
- **高效滤网**：给水上机安装后每日打捞量翻倍；取回机器时滤网会一并返还。

## 箱子式操作

- 单击背包物品 = 放 1 个到机器对应位置。
- Ctrl / Shift + 单击 = 整组放入。
- 单击机器里的物品 = 取 1 个到背包。
- Ctrl / Shift + 单击机器里的物品 = 整组取回。
- 水上机：鱼饵自动进饵料槽，其它物品自动进垃圾储存区。
- 陆地机：煤/木头自动进燃料区，其它物品自动进处理队列；不可回收物留在队列中不处理。

## 安装

1. 安装 [SMAPI](https://smapi.io/)（4.x）。
2. 将本 Mod 解压到 `Stardew Valley/Mods/GarbageRecycler`。
3. 启动游戏，制造配方会自动按等级解锁。

## 配方

| 物品 | 配方 | 解锁 |
|---|---|---|
| 水上垃圾回收机 | 木头×30 + 铁锭×2 + 精炼石英×1 | 钓鱼 4 级 |
| 陆地垃圾回收机 | 铁锭×3 + 石头×25 + 煤×5 | 采矿 4 级 |
| 净水滤芯 | 纤维×15 + 布×1 | 钓鱼 2 级 |
| 高效滤网 | 铁锭×2 + 布×2 + 精炼石英×1 | 钓鱼 6 级 |
| 水域监测站 | 电池组×1 + 铁锭×5 + 精炼石英×2 | 采矿 6 级 |

## 兼容

- SMAPI 4.x / 星露谷物语 1.6.15+
- 多人游戏仅主机可操作回收机与监测站
- 可选联动：Lookup Anything（监测站 F1 查看机器档案）
