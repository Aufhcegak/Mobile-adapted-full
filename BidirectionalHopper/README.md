# 双向漏斗 (Bidirectional Hopper)

星露谷物语 Mod - 改造原版自动加料器（Hopper），除了向上加料，还会把上方漏斗内的物品送到下方任意容器，并把下方机器加工完成的产物收回漏斗。

## 功能

- **向上加料**（原版功能）：从上方漏斗向下方机器投料
- **向下送料**：把上方漏斗内的原料自动投入下方机器（与原版加料同路）
- **收取产物**：机器加工完成的瞬间，自动把产物整份收进漏斗
- **即时触发**：只在机器完成、玩家交互、或每天早上时执行，不做全局轮询，性能友好

## 安装

1. 安装 [SMAPI](https://smapi.io/)
2. 下载本 Mod 解压到 `Stardew Valley/Mods/` 目录
3. 运行游戏

## 配置

使用 Generic Mod Config Menu 设置：
- 启用加料
- 启用收取
- 播放音效
- 调试日志
