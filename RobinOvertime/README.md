# 罗宾加班手机版 1.4.3-mobile.2

目标：星露谷 1.6.15 / Android SMAPI 4.3.2.5 手机运行器；电脑版 1.6.15 同样可用。

安装包的 `RobinOvertime` 文件夹放入手机 SMAPI 的 `Mods` 中，替换旧版同名文件夹内的运行文件。不要同时安装电脑版和手机版；旧 config.json 可以保留，原键名兼容。

点按罗宾打开加班页。多栋施工时，先按建筑名称、地点、坐标、剩余天数及费用选目标，再确认付款。下页、上页及取消按钮固定在底部；较长说明可上下拖动，右侧滚动条显示位置。按钮按下不提交，松手才执行；拖动、长按、旋转或窗口变化会取消本次按点。

## 建筑方向键

在罗宾的建造菜单里选择“移动建筑”，再点选要搬的建筑，松手后会出现方向键面板。

- 方向键每次移动一格；按住可连续移动。
- 只有确认才会搬过去。障碍物、门口通路、可移动建筑和玩家权限仍由游戏原版检查。
- 点“取消”可以取消这次预览，建筑保留原位置。
- 搬迁不收加班费。原有加班入口、费用、减时和完工规则保持。

### 电脑版

面板是上下左右、确认、取消六个按钮；点空白地面可粗调位置，拖动空白地面可以平移视野，预览不会跟着手指乱跳。原版红色退出按钮和退出键同样取消。

### 原生安卓（手机运行器）

两套建造菜单接口都支持，模组启动时自己判断用哪一套：

- 手机运行器的建造菜单没有桌面版的方向枚举，改用菜单自身的“移动中”状态和预览坐标，方向键直接改预览像素，界面上画四个方向键。
- 确认和取消用游戏自带的右下角确认按钮和红色退出按钮，面板不再重复画这两个键，避免和原版按钮打架。
- 如果运行器里这两套接口都对不上，模组会自动关掉搬迁面板，但**加班功能照常工作**，并在 SMAPI 日志里写明原因；不会出现“两个功能一起消失”。

在 Cinderbox 中，本模组的搬迁界面会让其内置建筑触控层暂时避让，避免两套确认按钮抢操作；不会改写它的开关配置。其他建造、升级、刷漆界面继续沿用原来的处理。

## 还是没反应怎么办

装包里的 `RobinOvertimeCheck` 文件夹（临时自检页，只读不写存档），启动游戏后在标题页会弹出四页报告：

- “概况”：SMAPI 版本、游戏版本、罗宾版本的加载状态、三个补丁是否已注册、方向键层的注册结果。
- “接口”：这台机器上建造菜单到底有哪些字段和方法，以及模组识别成哪套接口。
- “报错”：罗宾自己的日志。

把“概况”和“接口”两页截图发来即可定位，查完删掉 `RobinOvertimeCheck` 文件夹就行。

## 规则

沿用电脑版 1.4.2 规则：额外费用为该次建造或升级费用 × FeeMultiplier，默认 2；剩余工期减半，最后一天立即完工。农场建筑及房屋升级都适用，仍只有房主可执行世界变更。取消会回到原版罗宾交互。Generic Mod Config Menu 可选。

加班确认时补查工程仍存在且在施工、费用仍与页面一致；过期页面不会扣钱。搬迁只在最后确认时进入原版放置流程，预览不直接写建筑坐标。

构建显式关闭部署：`dotnet build RobinOvertime.csproj -c Release -p:DeployToMods=false -p:EnableModDeploy=false -p:EnableModZip=false`。本工程无自定义自动部署目标。

本轮验证与发行身份见工作区 `_robin_tools/native_move_fix_20261020/closure.json` 及 `ROBIN_OVERTIME_NATIVE_MOVE_REPORT_20261020.md`。Windows 原生场景 157/0（含反射层与假菜单用例）、原加班 591/0、逻辑 517/0；实体手机原生 SMAPI 4.3.2.5、玩家旧档和双客户端仍待用户确认。
