# 顺丰速递 PhoneGift

星露谷物语 1.6 打电话送礼 mod:一座「顺丰速递」电话亭,足不出户把礼物寄给地图上任何一个村民,还能**提前寄存生日礼物,生日当天自动送达**。

## 功能

- **电话送礼**:把电话放地上,右键打开送礼界面,点一个村民,选一件背包物品寄出(收取 500 金币运费,可在配置中修改)。
  - 送礼规则完全复刻原版:喜好/品质加成/生日 8 倍/夫妻减半/每周 2 次/每天 1 次/已离婚拒收。
  - 离线安全:村民不在当前地图也能送。
- **生日 tab**:全年所有村民生日,按「距离今天还有几天」排序,今天生日置顶金色高亮。
- **生日礼物(重磅)**:在生日 tab 里提前给村民寄存一份生日礼物(免费):
  - 生日当天自动送达,好感按生日 8 倍结算,并占掉当天的送礼机会;
  - 第二天起床走出家门那一刻,NPC 会弹出收礼对话(与正常送礼的对话一模一样,含生日专属台词);
  - 已寄存的人可随时「换一份」(旧礼物退回背包)或「取回」。
- **F1 查档案**:生日界面把鼠标停在村民身上按 F1,直接弹出 LookupAnything 的村民档案(装了 Lookup Anything 时)。

## 安装

1. 需要 [SMAPI](https://smapi.io/) 4.0+ 与星露谷物语 1.6.15+。
2. 把 `PhoneGift` 文件夹解压到 `Stardew Valley/Mods/` 下。
3. 启动游戏。采集 6 级后自动学会「顺丰速递」配方(铱锭×5 + 精炼石英×5 + 木头×50 + 石头×50)。

> 没有 Lookup Anything 时,F1 会提示不可用,其余功能不受影响。

## 配置(可选)

装了 Generic Mod Config Menu 后,在游戏内「选项 → Mod 配置」可调整:

| 选项 | 默认 | 说明 |
|---|---|---|
| 运费 | 500 | 寄一份礼物收取的金币 |
| 每人每天限送 1 次 | 开 | 与原版一致,关掉可无限送 |
| 每人每周限送 2 次 | 开 | 与原版一致,关掉可无限送 |
| 今天生日置顶 | 开 | 送礼列表里今天生日的人置顶金色高亮 |
| 配方所需采集等级 | 6 | 达到该等级次日学会配方 |

## 构建

```bash
dotnet build -c Release
```

编译产物自动复制到 `Mods/PhoneGift/` 自身。逻辑回归测试:

```bash
cd logic_test && dotnet run -c Release
```

## 兼容性

- SMAPI 4.x / 星露谷物语 1.6.15+
- 与 [Lookup Anything](https://www.nexusmods.com/stardewvalley/mods/541) 联动(F1 查档案,可选)
- 与 [Generic Mod Config Menu](https://www.nexusmods.com/stardewvalley/mods/5098) 联动(配置页,可选)
- 存档安全:所有状态存于玩家 modData,不修改原版存档结构,卸载后不影响存档
